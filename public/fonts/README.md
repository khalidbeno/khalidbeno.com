# Local fonts

Inter Tight Regular 400 and Roboto Mono Regular 400, Latin WOFF2 subsets from Google Fonts (22 October 2026). Both are distributed under the SIL Open Font License 1.1; see the accompanying OFL files for copyright and terms.

- Inter Tight: https://github.com/google/fonts/tree/main/ofl/intertight
- Roboto Mono: https://github.com/google/fonts/tree/main/ofl/robotomono

Served locally. No external font requests from the application. Inter Tight is the substitute explicitly authorized in the redesign brief.
